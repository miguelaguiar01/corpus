Corpus is a self-hosted translation workbench for the text an application shows people. It reads the message catalogues your repository already has, gives translators somewhere to work, and writes translations back as files you review and merge.

- New here: [What Corpus is](What-Corpus-is), then [Install and first push](Install-and-first-push).
- Wiring it in: [The config file](The-config-file), [Your i18n library](Your-i18n-library), [Corpus in CI](Corpus-in-CI).
- Running it: [The workbench](The-workbench), [A team instance](A-team-instance).
- Translating in it: [For translators](For-translators).

The [design spec](https://github.com/miguelaguiar01/corpus/blob/main/docs/corpus-design.md) is the normative reference. This wiki teaches; where a rule matters, the wiki says what happens and links to the section that defines it.
